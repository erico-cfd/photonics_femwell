[T4-6] Critical discussion -- what is certain, what is assumed, what is missing
==============================================================================

CERTAIN (from cited sources or algebra):
 - Resonance/FSR/Q relations (RABUS07, BOG12); series-ring transfer function
   (RABUS07 Eqs. 2.58-2.65), energy conservation checked numerically.
 - Vernier relation FSR_ext = N FSR1 = M FSR2 (RABUS07 2.77-2.78; GRIFFEL00).
 - L2 = L1/2 makes theta2 = theta1/2 identically: R2 anti-resonant at every odd
   order of R1 (pump), resonant at every even order (signal, idler) -- pure algebra.
 - PGR functional form (ARXIV2411 Eq. S1 / GENTRY18) and its calibration point.
 - Measured variability (ARXIV2411 Table 1) and measured filter performance.

ASSUMED (ours):
 - 2:1 Vernier ratio (read from the supervisor's comb slide).
 - Lossless, frequency-independent couplers; Butterworth k2, k3 rule.
 - kappa from the gap via CHROST15 Eq. 4.8 (straight coupler, L = 5 um); TE0 only.
 - Same cross-section for the PGR calibration transfer ((R_ref/R)^2 scaling).
 - Linear phase-matching term only; CW undepleted pump.

NOT CAPTURED (and known to matter):
 - IS IT NORMAL TO SEE NO PUMP AT THE DROP? The linear TMM gives only RELATIVE
   rejection (~tens of dB). The pump is ~1e9x stronger than the pairs, so even
   after this rejection RESIDUAL PUMP STILL DOMINATES -> physically pump photons
   remain. "T_drop ~ 0" is an idealisation. A realistic answer needs the ABSOLUTE
   power budget (1e9) + CASCADING to >100 dB + the scattered-light floor.
 - TPA / free-carrier absorption -> PGR is an upper bound (ARXIV2411; MEDINA24).
 - Scattered-light floor: AFIFI21 measured 60 dB vs 157 dB modelled -> model
   rejection is an upper bound.
 - Backscattering / resonance splitting from sidewall roughness (RABUS07 §2.1.1).
 - kappa uses Eq. 4.8 (straight coupler); circular-ring curved coupler + 3D FDTD
   are the next refinement.
 - lambda_p is an INPUT: the model predicts the response around it, it does not
   select it (supervisor's note).
